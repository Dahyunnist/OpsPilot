# S4 学习记录：评测、展示与投递材料

## 故障故事

值班人员输入告警 ID 后，调查器按指标信号选择日志、追踪和部署查询，输出根因或证据不足结论。报告显示每个假设的支持、反证、关联字段和原始记录 ID。高风险建议只进入审批卡，批准后也只模拟。

## 四类信号在评测中的角色

- **日志**保留原始错误文字；与仅日志策略对照，能量化它受误导文字影响的情况。
- **指标**作为调查首查，帮助选择低成本的后续查询。
- **追踪**通过 trace ID 定位单次请求的慢 span，并反证数据库池假设。
- **部署**通过版本和时间与失败配置校验信号对齐。

评测标签与调查输入分离。评测器读 `data/labels.json`，调查器只读取 `data/incidents.jsonl`。报告保留逐例原始查询和推理引用，摘要指标包含分子、分母、样本量与运行次数。

## 关键文件与运行方式

- `scripts/evaluate.py`：固定集两轮运行，比较多信号、仅日志和忽略反证的策略，并生成逐例 JSON 与摘要 Markdown。
- `reports/evaluation.json`：8 例完整首轮报告、真值、单例成本和第二轮稳定签名。
- `reports/evaluation.md`：摘要指标和适用范围。
- `docs/architecture.md`：组件、数据流、检查点与审批模拟器图。
- `scripts/setup.ps1`、`scripts/run_investigation.ps1`、`scripts/run_mcp.ps1`：本地安装、调查和 MCP 服务脚本。
- `docs/resume-bullets.md`：注明合成样本量和规则型原型边界的简历草稿。

运行完整检查：

```powershell
.\scripts\setup.ps1
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/evaluate.py
```

## 假设怎样被证实或否定

多信号报告必须逐条记录支持和反证，引用 ID 由本次查询返回。仅日志基线只读日志；无反证基线使用全部支持项但忽略 `against`，因此可留下看似成立的竞争假设。概率校准只适用于输出概率的模型；本项目规则没有概率，因此报告弃答正确率和假阳性确定数，不制造校准分数。

## 两条异常链

1. **数据库误导**：仅日志看到数据库池告警 → 日志基线把两个下游案例判成池耗尽 → 完整调查用低池利用率和慢下游 span 反证 → 多信号结论为下游超时。
2. **无反证遗留**：无反证基线按支持数选对总体根因，但保留 4 条有支持的竞争假设 → 完整账本再使用 contra evidence 标出应淘汰的解释 → 结论可复核，错误候选不再悄然留存。

## 亲手实验：给证据不足案例补一条 trace（约 10–20 分钟）

1. 复制 `data/incidents.jsonl` 到 `var/incidents-scratch.jsonl`。
2. 只修改副本中的 `unknown-01`：增加一个带唯一 `record_id`、窗口内 UTC 时间、稳定 trace ID、`order.downstream.call` span、长耗时和错误状态的追踪记录。
3. 用 `.\.venv\Scripts\python.exe -m opspilot investigate unknown-01 --data var/incidents-scratch.jsonl --no-state --no-audit --format json` 运行调查。
4. 查看追踪是否足以和现有 5xx 日志建立假设；若仍证据不足，再补相同 trace ID 的下游超时日志后重试。
5. 记录哪条新证据改变状态，以及为什么原始标签集仍不能用修改后的副本重新评测。

## 面试追问

**问：6/6 Top1 是否证明 Agent 生产准确率是 100%？**

答：不证明。结果来自 6 个预设根因的合成案例和确定性规则，不是生产样本，也没有模型推断。

**问：无反证策略根因准确率相同，反证还有什么价值？**

答：准确率只看最终首选根因；无反证结果仍留有 4 条支持过的竞争解释。反证记录解释这些候选为何被排除，改善可审阅性与处置安全。

**问：为什么 Token 成本为空？**

答：本阶段没有模型调用。把空值填成 0 会让人误以为测过模型 token；报告用“不适用”保留事实。

## 未覆盖边界

固定集只有 8 例且根因类型仅三类，不能外推真实准确率。规则评测不能代替盲测、概率校准或模型评测。运行脚本适用于本机演示，不是生产部署包；没有真实遥测、认证、并发审计存储或外部修复接口。
