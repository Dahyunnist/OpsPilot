## 本轮学习与验证

OP-1 控制器先检查所需镜像，再执行 `docker compose up --no-build`；服务只接收环境变量 `LAB_FAULT`，没有网络注入/清理路由；Compose 不挂载 `truth.json`，只读遥测采集器从 loopback 查询服务。故障真值由离线 scenario 文件供控制器与评分流程使用，不进入服务调查接口。恢复路径在注入后重建 orders/payment 并发 checkout 验证，但只有既有窗口记录或本机真实运行能证明效果。

本轮实验命令在镜像检查阶段失败：Docker Desktop Linux Engine pipe 不存在，且 `opspilot-lab-gateway:latest` 本地镜像缺失。脚本明确拒绝 build/pull；没有生成本轮故障窗、snapshot 或恢复证据。不得报告本轮故障复现。

离线回归新增两项检查，覆盖缺镜像拒绝顺序和 Compose 不挂载真值。完整测试结果记录在本次提交后补写。
