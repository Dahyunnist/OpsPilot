# S12：复杂集结果与选择性路由

测试集 16 例含 6 例可判定与 10 例应弃答。规则、单 Agent、多 Agent 的根因均为 6/6；证据不足均正确弃答 10/10，错误确定 0。单、多 Agent 金证据 P/R 都是 100%/85.7%；规则为 64.7%/78.6%。模型引用精度在这个小型合成集上有增益，根因与弃答没有增益。

最终验收在干净虚拟环境重跑同一冻结测试集：三路根因和弃答结果不变；多 Agent 金证据召回从 85.7% 变为 82.1%。新一轮缓存命中也改变了费用估算：单 Agent `$0.00242328`、多 Agent `$0.02814017`，比值约 11.6 倍。模型输出与缓存价格估算会随运行变化；上表是已提交评测那一次，不应描述为可逐 token 重现的固定结果。

验证集方向一致：规则、单、多 Agent 根因 9/9，弃答 7/7；单 Agent 与多 Agent 的金证据 P/R 相同。无需用多 Agent 支付额外调用来取得该集的证据收益。完整逐例响应、轨迹和统计见 [复杂盲测 JSON](../../reports/complex-agent-evaluation.json)、[验证 JSON](../../reports/complex-validation-evaluation.json)；Markdown 摘要与同名。

## 自动路由

`--mode auto` 先运行规则调查。若至少两个根因各有至少两个跨来源强支持引用，路由到单 Agent 复核；其余走规则，包括证据缺失时的安全弃答。该阈值只看实时调查报告，不读标签。

复杂验证集回放路由 6/16 到单 Agent、10/16 到规则：根因 9/9、弃答 7/7；金证据 P/R 为 85.7%/85.7%；估算费用 `$0.00208950`，模型调用 6 次。回放复用了同一验证集各路线已保存的预测，没有额外模型调用。[路由验证 JSON](../../reports/complex-routing-validation.json)。

多 Agent 保留为显式 `--mode multi-agent`，适用于人工要求独立专家记录、跨团队复核且能接受更高费用和约 6.6 秒平均延迟的争议。当前没有证据支持自动路由到多 Agent。路由回放尚未在未见测试集上验证；它不构成泛化收益证明。

## A2A 与简历边界

官方 SDK 客户端互通路径通过；本地服务器仍不支持 TLS、认证、streaming 或持久任务状态，不能作为生产 A2A 服务。数据全为合成字段和事件，不是生产事件，也不代表生产精度。

简历可以写冻结集大小、测试指标、成本和互通方法；必须同时写清测试集只有 6 个可判定样本，不能声称多 Agent 提升根因准确率或生产能力。可参考 `docs/resume-bullets.md`。
