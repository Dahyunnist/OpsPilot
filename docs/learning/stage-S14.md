# S14：预算受限的三路因果盲测

## 协议

在 S13 冻结的 30 例测试集上，对照 rules、single-agent、multi-agent；每条策略使用相同输入。模型为 `.env` 中配置的 DeepSeek V4 Flash。输出不参与训练，也未按测试结果调参。单 Agent 30 次模型调用，多 Agent 180 次；各路线失败均为 0。

双故障的两个根因没有天然先后顺序。因此主指标分别报告单根因准确率、活动根因 Top-1/Top-3、活动根因 Recall@3 和完整集合命中。双故障不按任意标签顺序判“主根因”。首次运行后只修正了该评分口径，并用原始模型输出离线重算；未改输入、标签或模型响应，也未再调用 API。

测试集含 18 个单根因、6 个双根因和 6 个不可判定案例。多 Agent 对完整根因集合的命中比单 Agent 高 25 个百分点，金证据召回高 16.7 个百分点；单根因准确率低 11.1 个百分点，活动根因 Top-1 低 8.3 个百分点。多 Agent 费用约为单 Agent 的 5 倍，平均延迟约 3.8 倍。所有策略都对 6 个证据不足样本正确弃答。

## 费用与结论

官方价格页在运行时列出 Flash 峰值输入 `$0.30/M`、输出 `$1.20/M`，非高峰减半。按运行时段的报告估算，本轮 API 费用 `$0.0833175`；账本另以峰值单价保守计为 `$0.166635`，低于本轮 `$0.50` 上限。费用是按 token 估算，不是账户账单。仓库没有 DeepSeek 账户账单导出，不能确认共享账户 `$4` 总额度的外部余额；历史报告估算见 `reports/api-cost-ledger.jsonl`，可能重叠，不能当作累计扣款证明。

结论：Multi-Agent 在这组多根因合成样本上有独立的集合召回和金证据收益，但更慢、更贵，且 Top-1 与单根因准确率更低。保留为显式 `--mode multi-agent` 实验路线；不加入默认 `auto` 路由。规则继续承担零模型成本基线，单 Agent 适合需要根因 Top-1 的复核。A2A 交互成功（30 次任务、120 次专家交接、695 次轮询、0 失败）只证明协议运行，不单独构成业务收益。

该结论只来自 24 个可判定合成案例，其中双故障只有 6 例，不能推及真实生产。公开多根因数据候选及许可边界见 S13。

S14 是对“所有样本都用单一策略”的直接比较结论。后续 S15 加入强证据门控，仅对冲突/弃答案例升级；validation 与新 seed 复测表明选择性 Multi-Agent 可保留集合收益，且成本更低。最终 `auto` 路线以 S15 为准。
