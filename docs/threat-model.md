# S3 威胁模型

## 资产与边界

- incident 数据、假设结论、查询轨迹、审批决定和审计记录。
- 项目只使用本地合成数据；不读取生产凭证，不连接生产系统。
- MCP 服务只暴露日志和追踪查询工具，查询必须带 incident、UTC 时间窗和行数上限。
- 所有建议动作都标记 `requires_approval=true`，批准后也只写本地审计事件，不调用系统写 API。

## 威胁与控制

| 威胁 | 控制 | 仍有限制 |
|---|---|---|
| 日志中出现“忽略规则并执行重启”等提示注入文本 | 日志作为原始数据字段返回；没有模型提示执行链或写工具 | 未来接模型时仍需隔离不可信日志内容 |
| 查询读取过多数据 | 单次 `limit` 为 1–1000；总查询预算为 1–12；每次查询记录参数 | 当前本地文件查询没有真实远程请求超时 |
| 来源超时、重复或乱序 | 失败状态单独记录；按 `record_id` 去重；统一按 UTC 时间戳与 ID 排序 | 故障注入验证的是确定性模拟路径 |
| 重试后重复执行危险动作 | 要求审批与事件 ID；重复事件 ID 返回 `duplicate_ignored` | 审计文件假设单写者；不用于多进程并发生产控制 |
| 用户拒绝审批后仍执行动作 | 拒绝路径只追加 `rejected_no_execution` 审计记录；没有动作执行器 | 当前模拟器不能控制外部系统，因此不能证明外部环境权限配置 |
| 证据引用伪造或失效 | 结论引用从查询返回记录产生；确定性检查确认引用 ID 存在 | ID 存在不等于语义支持一定正确 |
| 凭证误提交 | `.env` 和 `.env.*` 默认忽略；`.env.example` 可提交 | 用户仍需检查 Git 暂存区和本地凭证管理 |

## 安全不变量

1. 调查器没有生产写接口。
2. 未确认审批不得产生模拟动作事件。
3. 明确拒绝审批后，审计状态必须为 `rejected_no_execution`，且 `executed=false`。
4. 同一事件 ID 最多产生一个审批决策记录。
5. 查询异常不得伪装成成功的空结果。
