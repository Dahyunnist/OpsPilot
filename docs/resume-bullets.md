# OpsPilot 简历 bullet 草稿

- 构建本地证据驱动故障调查原型，统一查询指标、日志、追踪和部署记录；用 trace ID 与版本关联证据，并将支持、反证和未知项保存在可审计的假设账本中。
- 在固定 8 例合成数据上评测确定性规则：6 个已知根因案例 Top1 为 6/6，2 个证据不足案例均弃答；仅日志基线为 4/6。所有 32 条证据引用均可解析，6 条危险建议均要求审批；结果只说明该合成集，不代表生产或模型能力。
- 为本地只读日志与追踪工具提供 MCP stdio 服务；用标准 SDK 客户端联调，并为超时、重复、乱序、预算续跑、审批拒绝和事件幂等编写测试。
- 冻结独立 64 例合成跨服务冲突集并比较规则、单 Agent、多 Agent。16 例盲测上三者根因均为 6/6、证据不足均弃答 10/10；单与多 Agent 金证据 P/R 均为 100%/85.7%，规则为 64.7%/78.6%。多 Agent 用 96 次模型调用、121,437 tokens、约 `$0.02871`，单 Agent 用 16 次、21,383 tokens、约 `$0.00467`；无根因或引用增益。成本感知自动路由只在跨源强证据冲突时调用单 Agent，多 Agent 保留人工显式升级。
- 用官方 `a2a-sdk==0.3.8` 客户端验证本地 A2A v0.3 Agent Card、`message/send`、`tasks/get` 与 artifact 往返；只证明该客户端路径互通，不宣称完整协议或生产安全合规。

新盲测使用 DeepSeek V4 Flash 配置，均为项目合成数据。报告数字是一轮样本结果；干净环境复跑后，根因/弃答不变，但多 Agent 金证据召回与缓存费用估算有波动。不得写成确定性模型结果、生产验证或普遍模型提升。样本和字段边界见 `docs/learning/stage-S10.md` 至 `stage-S12.md`。
